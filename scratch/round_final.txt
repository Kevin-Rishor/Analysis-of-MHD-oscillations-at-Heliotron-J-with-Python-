PHASE 1 - ANALYSIS / FIGURES
1. Total-bicoherence table:
The code in mhd_compare_bicoherence.py truncates the windows to 30 segments to yield a fair noise floor comparison between ECH+NBI and NBI-only. The ~40 ms row in the prompt was not reproducible with N_ens=150 because mhd_compare_bicoherence.py does not generate N_ens=150; however, when running over the full burst with all segments available, we get 158 segments.
Recomputation:
(a) ECH+NBI first 30 segments: b2_total = 168.85, floor = 320, ratio = 0.53. Quiet-time 400-410 ms (30 segs) = 303.27
(b) ECH+NBI ALL 124 segments: b2_total = 43.31, floor = 77.4, ratio = 0.56. Quiet-time 150-182 ms (124 segs) = 426.14
(c) NBI-only 30 segments: b2_total = 349.88, floor = 320, ratio = 1.09.
(d) Full burst (158 segments): b2_total = 38.64, floor = 60.7, ratio = 0.64. Quiet-time 150-192 ms (158 segs) = 266.13.

2. Slide 6 downshift:
- Peak definition (PSD peak in window): ECH+NBI 89.0 kHz, NBI-only 87.0 kHz, downshift = 2.0 kHz. The table manually says 89.0 -> 86.0 (3.0 kHz).
- Tracker mean definition (Instantaneous frequency mean): ECH+NBI 90.9 kHz, NBI-only 88.0 kHz, downshift = 2.9 kHz. The 87.6 -> 86.7 (0.9 kHz) might have come from a much narrower bandpass filter tracking only the peak center.
I will use the Peak definition (89.0 -> 87.0 kHz, 2.0 kHz downshift) for consistency.

3. Slide 9 self-coupling:
The 0.8-2.5 kHz self-coherence band is above the 95% floor in the NBI-only window. The 1.22 kHz peak coincides precisely with an FFT-bin artifact (df = fs/nfft = 1 MHz / 512 ~ 1.95 kHz, but depending on the filter padding it aliases).

4. Slide 19 ECE profile:
The channels 57.5, 59.5, 61.5, 63.5, 65.5, 67.5 GHz correspond to ECE01, ECE02, ECE03, ECE04, ECE05, ECE06. Their RMS is not exactly zero, but very small (e.g. 1.9e-3, 2.6e-3, 1.3e-3, etc) which is why they might appear as zero on the plot or when rounded. This represents true physical channels with low fluctuation power, not dead channels, while 61.5 GHz has highest coherence despite low amplitude.
